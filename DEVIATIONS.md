# Deviations and pre-registered rulings

Every change to the plan, the ground truth, the scoring or a protocol after the project started, in the order it was
made. Each was recorded before the number it could affect was computed, unless the row says otherwise. Numbers and
dates are the project's own records. The frozen documents (`docs/CONTRACT.md`, `docs/RELATIONS.md`,
`docs/P1B_*.md`) carry the same changes in their change logs.

## Kill criterion K2 (mapper), written 2026-10-27 before any number

- **Rule:** if "ours" stays below ConceptGraphs on Replica mIoU after two tuning tasks, adopt the OVO / ConceptGraphs
  code as the map module and move on. The project's value is then the GT harness, the scoring and P1b.
- **"Replica mIoU"** is the protocol's headline number, **pooled** over the 8 scenes (summed confusion matrices).
  This reading was recorded on 2026-10-27 and pinned on 2026-10-28, before any number of the first attempt.
  Per-scene means are reported beside it and never substituted.
- **Successor rule,** written 2026-10-29 04:54 (CET), before the second attempt's counted number: if K2 fires, the
  map module is the baseline with the higher **HSSD dev 5 pooled object F1@0.25** (P1a's headline metric; dev only,
  eval stays held out). On the numbers then available that is ConceptGraphs (0.409 vs OVO 0.355). OVO stays as the
  second row of every table, and "ours" v1 / v2 are reported as attempts. If K2 does not fire, frozen v2 is "ours".
- **Outcome: K2 fired, 2 of 2, on 2026-10-29.**
  - Attempt 1 (2026-10-28): frozen v1, Replica pooled mIoU 13.03 < 15.80.
  - Attempt 2 (2026-10-29): frozen v2, Replica pooled mIoU 14.65 < 15.80.
  - Both were checked as design results, not implementation bugs: deletion proofs, a reduction to the earlier path,
    and oracles.
  - ConceptGraphs is the map module.
